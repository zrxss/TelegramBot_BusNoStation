# Telegram Bot для идеального выхода на остановку

Бот, который по кнопке начинает мониторить API Самарского общественного транспорта и по заданным параметрам
высылает вам уведомление в телеграме для выхода из дома.

## Технологии

- Python
- aiogram 3.x
- aiohttp

## Установка

1. Клонировать репозиторий:

```
git clone git@github.com:zrxss/BusNoStation.git
cd BusNoStation
``` 
2. Создать виртуальное окружение:
```
python -m venv .venv
source .venv/Scripts/activate
```
3. Установить зависимости:
```
pip install -r requirements.txt
```
## Настройка

Создать файл `config.py` по примеру `config.example.py`:
```
BOT_TOKEN = 'your_bot_token_here'

TG_PROXY = None  # Например: "http://login:password@host:port"

SECRET = "u38f9ud93f2h9f"   # Используется для подписи запросов к tosamara API

EXCLUDED_NEXT_STOP_IDS = set() # Фильтр который используется для исключения ошибочных прибытий возле конечных остановок.
KR_ID = 'your_bus_id'
KS_ID = 'your_stop_id'
```
ID вашего автобуса и остановки можно найти в приложенных мной справочниках
- [Автобусы и KR_ID](docs/bus_route_kr_ids.txt)
- [Остановки и KS_ID](docs/bus_stop_ks_ids.txt)


Так же стоит настроить минимальное и максимальное время ожидания, а так же ваше время в пути до остановки
(лучше всегда закладывайте погрешность) в `way_time.py`
 

## Запуск
```
python main.py
```
## Структура проекта, подробно

### main.py - Запуск и мониторинг
Запускается бот, начинается мониторинг на 10 минут и каждые 5 секунд отправляется запрос для проверки
автобусов на API Самарского общественного транспорта

### calculates.py - Создание запроса с подписью для API
Создается запрос для API и подписывается подписью найденной на бэке сайта мониторинга Самарского общественного транспорта

### way_time.py - Просчет времени когда пора выходить из дома

```commandline
    target_min_wait = 180 - минимальное время которое вы готовы ждать и в которое можно заложить погрешности
    target_max_wait = 300 - максимальное время которое вы готовы ждать и в которое можно заложить погрешности

    for bus in arrival:
        wait_time = float(bus['timeInSeconds']) - 210 - время ожидание которое вычисляется: время пребывания автобуса на остановку - время вашего пути до остановки 
        if target_min_wait <= wait_time <= target_max_wait and bus['nextStopId'] not in EXCLUDED_NEXT_STOP_IDS:
            return True
    return False
```
