# Telegram Bot для идеального выхода на остановку

Бот, который по команде начинает мониторить API Самарского общественного транспорта и по заданным параметрам
высылает вам уведомление в Telegram о том, что пора выходить из дома.

## Технологии

* Python
* aiogram 3.x
* aiohttp

## Установка

1. Клонировать репозиторий:

```
git clone git@github.com:zrxss/TelegramBot_BusNoStation.git
cd TelegramBot_BusNoStation
```

2. Создать виртуальное окружение:

```
python -m venv .venv
source .venv/Scripts/activate
```

3. Установить зависимости:

```
pip install -r requirements.txt
```

## Настройка

Создать файл `config.py` по примеру `config.example.py`:

```
BOT_TOKEN = 'your_bot_token_here'

TG_PROXY = None  # Например: "http://login:password@host:port"

SECRET = "u38f9ud93f2h9f"  # Используется для подписи запросов к tosamara API

EXCLUDED_NEXT_STOP_IDS = set()  # Фильтр для исключения ошибочных прибытий возле конечных остановок

KR_ID = 49  # ID маршрута и направления
KS_ID = 27  # ID остановки и стороны дороги

WALKING_TIME_SECONDS = 210  # Время пути до остановки
MIN_WAIT_SECONDS = 180  # Минимальное время ожидания
MAX_WAIT_SECONDS = 300  # Максимальное время ожидания
```

ID вашего маршрута и остановки можно найти в приложенных справочниках:

* [Автобусы и KR_ID](docs/bus_route_kr_ids.txt)
* [Остановки и KS_ID](docs/bus_stop_ks_ids.txt)

Также стоит настроить минимальное и максимальное время ожидания, а также ваше время в пути до остановки
в `config.py`. Лучше всегда закладывать небольшую погрешность.

## Запуск

```
python main.py
```

## Структура проекта, подробно

### main.py — запуск и мониторинг

Запускается бот, мониторинг начинается на 10 минут, и каждые 5 секунд отправляется запрос для проверки
автобусов через API Самарского общественного транспорта.

### calculates.py — создание запроса с подписью для API

Создаётся запрос для API и подписывается с помощью параметров подписи, найденных в клиентском коде сайта
мониторинга Самарского общественного транспорта.

### way_time.py — расчёт времени, когда пора выходить из дома

```
MIN_WAIT_SECONDS = 180 — минимальное время, которое вы готовы ждать и в которое можно заложить погрешность
MAX_WAIT_SECONDS = 300 — максимальное время, которое вы готовы ждать

Для каждого прибывающего автобуса:

wait_time = время прибытия автобуса на остановку - время вашего пути до остановки

Если wait_time находится между MIN_WAIT_SECONDS и MAX_WAIT_SECONDS,
а следующая остановка не входит в EXCLUDED_NEXT_STOP_IDS, функция возвращает True.
```

## Ограничения

* Бот рассчитан на мониторинг одного маршрута и одной остановки.
