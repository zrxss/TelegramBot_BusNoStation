KR_ID АВТОБУСНЫХ МАРШРУТОВ САМАРЫ, август 2026
============================================================

Как пользоваться:
1. Нажмите Ctrl+F и введите номер нужного автобуса.
2. Найдите нужное направление движения.
3. Скопируйте указанный KR_ID и подставьте его в настройки бота.

Важно:
- Один номер маршрута обычно имеет разные KR_ID для разных направлений.
- Направление означает конечную точку, КУДА едет автобус.
- В список включены только автобусы, для которых API предоставляет
  прогноз прибытия в реальном времени (realtimeForecast = 1).
- Метро, трамваи, троллейбусы, электрички и маршруты без
  онлайн-прогноза сюда не включены.

Пример:
Маршрут 47 — Городской муниципальный маршрут
  KR_ID 49  -> Хлебная площадь
  KR_ID 50  -> Юнгородок
